# Notebooks for *Prime Numbers and the Riemann Hypothesis*

Interactive companion notebooks to **Prime Numbers and the Riemann Hypothesis** by Barry Mazur and William Stein (Cambridge University Press, 2016). They follow the book's order, quote it, and turn the code that drew the book's figures into explanations with interactive controls. The last notebook is new. It covers the quasi-Riemann Hypothesis, proved in 2026.

**Running them.** Each "Open in Sagebrush" link loads that notebook, and the data file it reads, into a browser tab; press Run all. Nothing to install. They use the SageMath kernel, with numpy, scipy, matplotlib and mpmath. They run in the browser with [Sagebrush](https://sagebrush.space), and in SageMath's own Jupyter. Notebooks 6, 8, 9 and 10 read `zeta_zeros_1000.txt`, which holds the first 1000 zeros of $\zeta(s)$ computed with mpmath. Keep it in the same folder.
